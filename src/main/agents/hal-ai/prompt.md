# slime-cli使用

**安装路径**：~/.local/bin/slime-cli
**常用命令**：

- 查看全部帮助：`~/.local/bin/slime-cli help`
- 查看logs命令的帮助：`~/.local/bin/slime-cli help logs`
- 获取Slime日志：`~/.local/bin/slime-cli logs <flags> <args>`
