要在 Slime 中构建什么？

完全访问权限 Slime ▾ 本地模式 ▾ brave ▾

整体布局原则

左侧保持 Codex-like 半透明导航，右侧为圆角工作区。主内容优先服务任务流，顶部工具栏、输入器、右侧工具面板都应保持低噪声和稳定尺寸。

推荐分区

Sidebar / Workspace / Inspector 三段式是复杂工作台的默认骨架；简单页面可以只保留 Sidebar + Workspace。

适用页面

Chatroom、GroupChat、Gateway、Agents、Schedule 和 Settings 都应沿用同一窗口外壳，再根据页面任务选择是否展示右侧工具面板。
